## 二、技术定性承诺

### 2.1 仅推理，不训练

本企业承诺，本模型在部署运行期间，**仅执行前向推理（Inference），不执行任何形式的模型训练**，包括但不限于：

| 行为 | 是否实施 | 技术说明 |
|------|---------|---------|
| 预训练（Pre-training） | ❌ 否 | — |
| 监督微调（SFT） | ❌ 否 | — |
| LoRA / QLoRA 微调 | ❌ 否 | — |
| 强化学习对齐（RLHF/DPO） | ❌ 否 | — |
| 持续预训练（Continual Pre-training） | ❌ 否 | — |
| 在线学习 / 增量训练 | ❌ 否 | — |
| 知识蒸馏 / 模型压缩 | ❌ 否 | — |
| 权重量化适配（INT4/FP16） | ✅ 是 | 仅格式转换，不改变模型行为 |
| GGUF 格式转换 | ✅ 是 | 仅格式转换，不改变模型行为 |

### 2.2 权重不变更

本企业承诺，**不修改、不更新、不替换模型权重参数**。具体措施：

1. 模型权重文件（`.gguf`）部署后设置只读权限，仅运维人员可访问
2. 不提供任何修改权重的 API 或工具
3. 系统提示词（System Prompt）、RAG 知识库、用户对话**仅作为推理输入拼入上下文，不回写模型权重**
4. 如需更换模型版本，将另行向网信部门履行变更报备

### 2.3 数据不回传

本企业承诺，**用户对话数据、推理输入输出均不回传至模型原厂商或任何第三方**：

1. 所有对话数据存储于企业本地数据库（SQLite），不离开部署机器
2. 不调用任何外部 API（OpenAI / 阿里云 / 百度等）
3. 不上传用户数据用于模型优化
4. 推理全程在本地 CPU/GPU 完成

### 2.4 RAG 知识库说明

本系统使用检索增强生成（RAG）技术，将企业内部知识库文档（产品政策、申请材料、业务流程等）作为上下文提供给模型。此操作：

- ✅ 仅将知识库文本拼入推理输入（Prompt）
- ✅ 不更新模型权重
- ✅ 不改变模型基座行为
- ✅ 等同于"提供参考资料的问答"，不属于模型训练

## 三、技术验证

### 3.1 代码层面验证

本承诺可通过以下技术手段验证：

```bash
# 1. 验证模型权重未被修改（哈希应与原始一致）
sha256sum models/Qwen3-4B.gguf
# 预期输出：00fe7986ff5f6b463e62455821146049db6f9313603938a70800d1fb69ef11a4

# 2. 检查代码中无训练/微调相关依赖
grep -ri "train\|finetune\|lora\|backward\|optimizer\|gradient" internal/
# 预期：无匹配（仅推理路径）

# 3. 检查模型文件权限（应为只读）
ls -la models/*.gguf
# 预期：-r--r--r-- 或类似只读权限
```

### 3.2 架构层面验证

系统架构明确分为三层，推理层与训练层完全隔离：

```
┌─────────────────────────────────┐
│  应用层：用户交互 + 业务逻辑       │
├─────────────────────────────────┤
│  安全层：Guard + Compliance 过滤  │
├─────────────────────────────────┤
│  推理层：模型前向推理（仅读权重）   │ ← 无反向传播路径
└─────────────────────────────────┘
```

推理引擎（llama.cpp / Ollama）在编译配置中已禁用训练功能，仅包含前向推理算子。
