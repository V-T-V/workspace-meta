# 系统架构白皮书

> auto-finance-assistant 汽车金融本地智能客服系统  
> 版本：v2.9.2 | 日期：2026-07-27

---

## 一、系统概述

### 1.1 定位

本系统是面向汽车金融业务的**本地化部署智能客服系统**，提供贷款咨询、产品政策解答、业务流程引导等服务。

### 1.2 核心特征

- **全本地化部署**：模型推理、数据存储、知识库均在本地服务器，不依赖外部 API
- **仅推理不训练**：使用开源预训练模型，仅执行前向推理，不修改权重
- **三层安全架构**：应用层、安全过滤层、推理层物理隔离
- **数据不出域**：所有用户对话数据存储于本地，不回传第三方

## 二、技术架构

### 2.1 三层架构图

```
┌──────────────────────────────────────────────────────────────────┐
│                        【应用层】                                │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐        │
│  │ 客服问答  │  │ 知识库   │  │ 金融试算  │  │ 管理后台  │        │
│  │ Vue 前端  │  │ 管理系统  │  │ 工具     │  │ (认证)   │        │
│  └─────┬────┘  └─────┬────┘  └─────┬────┘  └─────┬────┘        │
│        │             │             │             │              │
│        └─────────────┴─────────────┴─────────────┘              │
│                           HTTP API                               │
├──────────────────────────────────────────────────────────────────┤
│                       【安全过滤层】                              │
│  ┌────────────┐  ┌────────────┐  ┌────────────┐  ┌───────────┐ │
│  │ PII 脱敏   │  │ Guard 输入  │  │ Compliance │  │ Guard 输出 │ │
│  │ MaskPII()  │  │ 预检拦截    │  │ 合规检查   │  │ 后检查    │ │
│  └────────────┘  └────────────┘  └────────────┘  └───────────┘ │
│  ┌────────────┐  ┌────────────┐  ┌──────────────────────────┐  │
│  │ Rate Limit │  │ Auth 认证   │  │ 审计日志 AuditLog        │  │
│  └────────────┘  └────────────┘  └──────────────────────────┘  │
├──────────────────────────────────────────────────────────────────┤
│                        【推理层】                                │
│  ┌──────────────────────┐    ┌─────────────────────────────┐   │
│  │ RAG 检索增强          │    │ 模型推理（仅前向）           │   │
│  │ FTS + 向量检索融合    │───→│ Qwen3-4B (GGUF Q4_K_M)     │   │
│  │ 本地知识库 (SQLite)   │    │ llama.cpp / Ollama         │   │
│  └──────────────────────┘    └─────────────────────────────┘   │

├──────────────────────────────────────────────────────────────────┤
│                        【存储层】                                │
│  SQLite (WAL) │ 文档存储 │ 日志(轮转60天) │ 备份(保留7份)       │
└──────────────────────────────────────────────────────────────────┘
```

### 2.2 推理链路流程

```
用户提问
  │
  ├─ 1. PII 脱敏 (MaskPII)
  │
  ├─ 2. Guard 输入预检
  │    ├─ 闲聊问候 → 预设回复（0ms，不调模型）
  │    ├─ 注入/越狱 → 拒绝（0ms）
  │    ├─ 无关话题 → 拒绝（0ms）
  │    ├─ 脏话 → 拒绝（0ms）
  │    └─ 通过 ↓
  │
  ├─ 3. Compliance 合规检查
  │    ├─ 承诺审批 → 合规拒答（0ms）
  │    └─ 通过 ↓
  │
  ├─ 4. FAQ 精确匹配
  │    ├─ 高置信命中 → 标准答案（<1ms）
  │    └─ 未命中 ↓
  │
  ├─ 5. 回答缓存 (LRU)
  │    ├─ 缓存命中 → 直接返回（<1ms）
  │    └─ 未命中 ↓
  │
  ├─ 6. RAG 检索（并行 FTS + 向量）
  │    └─ 检索知识库片段作为上下文 ↓
  │
  ├─ 7. 模型推理（仅前向）
  │    └─ Qwen3-4B 生成回答（流式输出）↓
  │
  ├─ 8. Guard 输出后检查
  │    ├─ 脏话/敏感内容 → 安全替换
  │    └─ 字数控制（≤300字）↓
  │
  ├─ 9. 业务引导追加
  │    └─ 末尾追加后续问题引导 ↓
  │
  └─ 返回用户 + 审计日志写入
```

## 三、数据流与存储

### 3.1 数据流向

```
用户输入
  ↓
[PII 脱敏] → 脱敏后文本（手机→138****5678）
  ↓
[模型推理] → 生成回答
  ↓
[本地 SQLite] 存储对话历史（脱敏）
  ↓
[本地日志] JSON 结构化日志（60天轮转）
```

**关键保证**：数据全程不离开本地服务器，不回传模型厂商。

### 3.2 存储位置

| 数据类型 | 存储位置 | 保留期 | 加密 |
|----------|---------|--------|------|
| 对话历史 | `data/assistant.db` (SQLite) | 90天 TTL | ❌ 需补充磁盘加密 |
| 知识库文档 | `data/documents/` | 永久 | ❌ |
| 审计日志 | `audit_logs` 表 | 90天 TTL | ❌ |
| 运行日志 | `data/logs/*.log` | 60天轮转 | ❌ |
| 备份文件 | `data/backups/` | 保留7份 | ❌ |
| 模型权重 | `models/*.gguf` | 永久（只读） | ❌ |

### 3.3 数据清理机制

- 启动时自动清理：`PurgeExpiredData()` 删除超 90 天的会话/消息/反馈/审计日志
- 每日定时清理：goroutine 每 24 小时执行一次
- 手动触发：`POST /api/system/purge?days=90`（需管理员认证 + 审计）

## 四、安全机制

### 4.1 输入安全（Guard 层）

| 防护维度 | 实现 | 响应时间 |
|----------|------|---------|
| Prompt 注入 | 30+ 特征模式匹配 | 2ms |
| 角色扮演攻击 | DAN/越狱模式检测 | 2ms |
| 脏话/侮辱 | 28 个中英文脏话词 | 2ms |
| 无关话题 | 50+ 关键词（天气/政治/编程等） | 2ms |
| 竞品对比 | ChatGPT/Claude/Gemini 等 | 2ms |
| 超长输入 | >500 字符截断 | 2ms |

### 4.2 输出安全

| 防护维度 | 实现 |
|----------|------|
| 脏话检测 | profanityWords 词表 |
| 敏感内容 | 歧视/暴力/违法建议（洗钱/诈骗等 20+ 词） |
| 空回答兜底 | 安全替换消息 |
| 字数控制 | 硬性截断 300 字 |

### 4.3 合规红线

| 红线 | 拦截方式 | 处理 |
|------|---------|------|
| 承诺审批通过 | 意图词+名词组合 | 拒答+转人工 |
| 承诺放款时间 | 同上 | 拒答+转人工 |
| 承诺费用减免 | 同上 | 拒答+转人工 |
| 泄露内部风控 | 关键词 | 拒答+转人工 |

### 4.4 访问控制

| 接口类型 | 认证 | 频率限制 |
|----------|------|---------|
| 聊天 API | 无（开放） | 10/min |
| 管理 API | X-Admin-Password | 30/min |
| 反馈提交 | 无（开放） | 10/min |

## 五、推理引擎说明

### 5.1 模型部署

| 项目 | 说明 |
|------|------|
| 推理引擎 | llama.cpp（主）/ Ollama（备） |
| 模型格式 | GGUF Q4_K_M（4-bit 量化） |
| GPU 加速 | 支持 NVIDIA CUDA（-ngl 99 全层 offload） |
| CPU 模式 | 支持（-t 8 线程） |
| 模型预热 | 启动时发送 dummy 请求，避免冷启动延迟 |
| Keep-Alive | 30 分钟（推理后模型常驻显存） |

### 5.2 性能指标（RTX 4060 生产环境）

| 指标 | 值 |
|------|-----|
| 平均推理速度 | 10-20 tok/s（GPU）/ 5-10 tok/s（CPU） |
| 首响应延迟 | 2-5s（含 Guard 检查） |
| Guard 拦截延迟 | 2-4ms |
| 缓存命中延迟 | <1ms |
| FAQ 命中延迟 | <50ms |

### 5.3 无训练能力证明

推理引擎（llama.cpp）编译配置：
- ✅ 仅包含前向推理算子
- ❌ 不包含反向传播（backward pass）
- ❌ 不包含优化器（optimizer）
- ❌ 不包含梯度计算（gradient）
- 模型权重文件权限：只读

## 六、部署拓扑

### 6.1 单机部署（当前方案）

```
┌─────────── 单台服务器 ───────────┐
│  Vue 前端（嵌入 Go 二进制）       │
│  Go 服务（HTTP API + 业务逻辑）   │
│  llama.cpp / Ollama（推理引擎）   │
│  SQLite（数据存储）               │
│  模型权重（GGUF）                 │
│  知识库文档                       │
└──────────────────────────────────┘
       ↕ (可选：仅限本地网络)
    企业内网用户
```

### 6.2 网络隔离

- 默认监听 `127.0.0.1:8080`（仅本地访问）
- 如需局域网访问：改 `0.0.0.0` + 必须设置 `admin_password`
- 无任何外部网络依赖（可完全离线运行）
