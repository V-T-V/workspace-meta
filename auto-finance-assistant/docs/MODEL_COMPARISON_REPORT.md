## 五、反直觉发现

### 5.1 "越大越好"是错的

```
qwen2.5:1.5b (1.5B) → 90% 准确率
qwen2.5:3b   (3.1B) → 60% 准确率  ← 大 2 倍但准确率更低！
```

可能原因：3B 模型的 RLHF 对齐对中文金融领域过度泛化，导致"安全但不准确"的回答。

### 5.2 Qwen3 思考链是双刃剑

```
qwen3:4b 直接调 API → 50% 准确率（思考链吃掉输出预算）
qwen3:4b 通过服务端（max_output_tokens=0）→ 答案正常
```

在服务端配置中，Qwen3 需要 `max_output_tokens=0`（不限），否则思考链会截断实际回答。

### 5.3 Gemma3 中文能力超出预期

Google 的 gemma3:latest 在中文金融场景达到 90% 准确率，与 Qwen2.5:1.5b 并列。但体积大 3.3 倍，速度慢 1.7 倍，性价比不如 Qwen。
