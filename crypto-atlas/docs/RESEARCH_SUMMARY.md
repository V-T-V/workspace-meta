# 密码学算法全景与选型指南

> crypto-atlas 的 9 算法分类 + 横向对比 + 选型建议。

## 一、四大家族

### 1. 古典密码（已被淘汰，纯教学）
| 算法 | 类型 | 安全性 | 教学价值 |
|------|------|--------|----------|
| 凯撒 | 单表替换 | 零（25 key 暴力） | 引入"密钥/加密/解密"概念 |
| 维吉尼亚 | 多表替换 | 弱（Kasiski 1863 破） | 引入"多表"抗频率分析 |
| XOR | 流密码鼻祖 | 弱（已知明文攻击） | 对称加密的数学基础（XOR 自反） |

**共性**：都是**替换式**，安全性靠"密钥保密"。古典密码的衰落 = 频率分析 + 计算能力提升。

### 2. 对称加密（现代主力）
| 算法 | 块大小 | 密钥长度 | 状态 |
|------|--------|----------|------|
| AES | 16 字节 | 128/192/256 位 | ✅ 标准，无已知有效攻击 |
| DES | 8 字节 | 56 位 | ❌ 已淘汰（1998 年 22 小时暴力破解）|

**共性**：加密解密用**同一把密钥**。问题：如何安全共享密钥？→ 公钥密码解决。

### 3. 哈希（单向函数）
| 算法 | 输出长度 | 状态 |
|------|----------|------|
| SHA-256 | 32 字节 | ✅ 标准 |
| MD5 | 16 字节 | ❌ 已不安全（2004 王小云碰撞）|

**共性**：**无密钥、不可逆**。用途：完整性校验、密码存储、数字签名、区块链。

### 4. 公钥密码（解决密钥分发）
| 算法 | 解决问题 | 数学基础 |
|------|----------|----------|
| RSA | 加密 + 签名 | 大整数分解难题 |
| DH | 密钥交换 | 离散对数难题 |

**共性**：公钥/私钥分离。公钥可公开，私钥保密。解决了对称密码的"密钥分发难题"。

## 二、选型指南

### 按场景

| 场景 | 推荐 | 理由 |
|------|------|------|
| 加密大量数据 | **AES-256-CBC/GCM** | 对称加密快，AES 无已知攻击 |
| 密码存储 | **bcrypt/argon2**（本库未含，用 SHA-256+salt 示意）| 抗彩虹表/暴力 |
| 文件/消息完整性 | **SHA-256** | 标准哈希 |
| 数字签名 | **RSA-PSS / ECDSA** | 公钥签名 |
| 密钥交换（TLS） | **DH/ECDH** | 前向保密 |
| 任何新系统 | **AES + SHA-256 + RSA/DH** | 现代标配 |

### 按安全需求

- **绝不要用**：凯撒/维吉尼亚/XOR（教学）、MD5（碰撞）、DES（56 位）、ECB 模式（重复明文泄漏）
- **可以用**：AES-CBC/GCM、SHA-256、RSA-2048+、ECDH
- **前沿**：后量子密码（Kyber/Dilithium，NIST 2024 标准化）

## 三、算法间的演进关系

```
  古典密码（替换式，靠密钥保密）
      │
      │ 频率分析破解 → 需要更强算法
      ▼
  对称加密（AES/DES，复杂的多轮替换+置换）
      │
      │ 密钥分发难题 → 如何安全共享对称密钥？
      ▼
  公钥密码（RSA/DH，数学难题保证安全）
      │
      │ 公钥密码慢 → 混合加密
      ▼
  现代系统：DH 交换对称密钥 → AES 加密数据 → SHA-256 校验 → RSA 签名
```

**关键洞察**：
- **凯撒 → AES**：替换从"固定位移"到"密钥动态生成的多轮 S-Box"，频率分析完全失效。
- **对称 → 公钥**：公钥解决了"如何安全分发对称密钥"，但公钥运算慢，所以**混合**用（公钥交换对称密钥，对称加密数据）。
- **MD5 → SHA-256**：碰撞攻击让 MD5 从"安全哈希"变成"只能做校验和"。
- **RSA vs DH**：RSA 能加密+签名，DH 只能交换密钥；TLS 同时用两者（DH 交换密钥，RSA/ECDSA 签名证书）。

## 五、M2 候选

- 3DES（DES 的过渡方案）
- ChaCha20（现代流密码）
- HMAC（带密钥的哈希）
- ECDSA（椭圆曲线签名）
- TLS 1.2 握手模拟（综合应用）
- 后量子密码（Kyber/Dilithium 入门）
