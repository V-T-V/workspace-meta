# 维吉尼亚密码 · 设计笔记

## 历史

- 真正的发明者是意大利人 **Giovan Battista Bellaso**（1553 年），他首次描述了这种多表密码
- 19 世纪被误归功于法国人 **Blaise de Vigenère**，名字沿用至今（历史误会）
- 在长达约 300 年里被称为 **"Le Chiffre Indéchiffrable"（不可破译的密码）**
- 直到 **1863 年普鲁士军官 Friedrich Kasiski** 发表重复间距分析法，才被系统性破解

## 核心算法

```
把密钥循环拉长到与明文等长：
    ATTACKATDAWN
    LEMONLEMONLE
每位用密钥字母的位移加密（注意最后一位 N(13)+E(4)=R(17)）：
    ATTACKATDAWN  →  LXFOPVEFRNHR
    加密：C[i] = (P[i] + K[i mod len(K)]) mod 26
    解密：P[i] = (C[i] - K[i mod len(K)] mod 26 + 26) mod 26
```

只处理英文字母（A-Z/a-z），密钥大小写不敏感统一转大写；非字母字符原样保留且不消耗密钥。

## 最小可识别特征

1. **替换式**：每个明文字母被映射成密文字母
2. **多表**：不同位置的同一个明文字母可能映射到不同密文字母（取决于密钥对应位）
3. **循环密钥**：密钥短于明文时循环复用（这是被 Kasiski 攻击的根源）

## 判定红线

- 如果"全文明文用同一个位移" → 是凯撒（单表），**不是**维吉尼亚
- 如果密钥与明文等长且不循环（一次性密钥本，OTP）→ 是一次性密码本，**不是**维吉尼亚
- 如果位移不是按字母表位移、而是按查表（Vigenère tableau）任意替换 → 仍是维吉尼亚族的变体，但本包只实现"位移"版本

## 与凯撒的区别

| 维度 | 凯撒 | 维吉尼亚 |
|------|------|----------|
| 表数 | 单表 | 多表（密钥长度 = 表数） |
| 同一字母的密文 | 永远相同 | 随位置变化 |
| 密钥空间 | 25 | 26^n（n = 密钥长度） |
| 抗简单频率分析 | 不抗 | 抗 |

## 安全性分析

- **抗简单频率分析**：同一个明文字母在密文中表现为多个不同字母，单字母频率被拉平
- **但不抗 Kasiski 攻击**：密钥循环复用导致密文中出现"相同明文块 → 相同密文块"的重复
  - 测量重复密文块之间的间距，对间距做因式分解，公因数很可能就是密钥长度
  - 一旦知道密钥长度 n，把密文按 n 列分组，每列就是一组凯撒密码，逐列频率分析即可
- 1863 年 Kasiski 之后，维吉尼亚彻底告别"不可破译"

## 与现代密码的关系

维吉尼亚揭示了密码学的一条铁律：**"看起来复杂" ≠ 安全**。
真正安全的版本是密钥与明文等长、绝不复用的一次性密码本（OTP，Shannon 证明信息论安全），
但 OTP 的密钥分发代价过高。现代流密码（ChaCha20）用"伪随机密钥流 + XOR"模拟 OTP，
用密钥扩展算法避免密钥复用——本质是"安全的、可实用的维吉尼亚思想"。

## 本包实现要点

- 密钥大小写不敏感，统一转大写；密钥中的非字母字符被丢弃
- 明文保留大小写与非字母字符（非字母不消耗密钥，原样透传）
- 密钥去掉非字母后为空 → 视为"无位移"，原样返回明文（不报错，便于教学）
- 解密用 `(r - shift + 26) % 26` 处理减法的负数情况
