# 凯撒密码 · 设计笔记

## 历史

- 罗马皇帝凯撒（公元前 100-44 年）用于军事通信
- 苏埃托尼乌斯《罗马十二帝王传》记载：凯撒把字母向后移 3 位
- 是已知最早的军事密码之一

## 核心算法

```
加密：E(x) = (x + key) mod 26
解密：D(x) = (x - key) mod 26
        ↑ x 是字母在字母表中的位置（A=0, B=1, ..., Z=25）
```

只处理英文字母（A-Z, a-z），保留大小写；非字母字符不变。

## 最小可识别特征

1. **替换式**：每个明文字母固定映射到一个密文字母
2. **单表**：映射规则对全文一致（同一个字母总是变成同一个密文字母）
3. **位移**：映射规则是"按字母表移 key 位"

## 判定红线

- 如果"位移"是字母表上的任意排列（而非固定 key 位移）→ 是一般替换密码，不是凯撒
- 如果不同位置用不同位移 → 是维吉尼亚（多表密码）

## 安全性分析（为什么它是"零安全性"）

- **密钥空间极小**：只有 25 个有效 key（0 不算加密），暴力穷举瞬间破解
- **不抗频率分析**：英文中 E/T/A 出现频率最高，统计密文字母频率即可反推 key
- 频率分析法在 9 世纪由阿拉伯学者肯迪发明，比凯撒密码晚约 900 年

## 与现代密码的关系

凯撒是**替换式密码**的鼻祖。现代分组密码（AES）本质上也是"替换"+ "置换"的多次迭代，
但替换表由密钥动态生成（而非固定位移），且每轮都打乱位置（ diffusion），
使得频率分析完全失效。从凯撒到 AES 的演进，就是密码学从"艺术"到"科学"的历史。

## 本包实现要点

- key 自动取模到 0-25（支持负数、大数）
- 保留大小写和非字母字符（实际凯撒只处理大写，本包扩展为大小写都处理）
- 解密 = 加密 -key（复用 Encrypt）
