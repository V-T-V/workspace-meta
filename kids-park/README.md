# KidsPark · 儿童 3D 乐园探索

> **Godot 4.7** · 3-8 岁 · 动物森友会简化版 · 60+ GDScript 脚本 · 55+ 玩法系统

无惩罚、即时正反馈、零文字依赖的儿童乐园。在 4 个主题区域自由探索 → 拾取发光物品 → 帮 NPC 小动物找东西 → 完成每日任务 → 跳绳/捉迷藏 → 解锁新区域。

---

## 一句话
儿童 3D 乐园探索：在 4 个彩色区域（草地/沙滩/花园/冰雪）自由走动 → 拾取 14 种发光物品 → 帮 4 位小动物朋友找东西、聊天听故事 → 获得宠物伴灵 → 拍照/钓鱼/荡秋千/开宝箱/跳绳 → 解锁新区域、收集图鉴、刷新每日任务。

## 快速开始

```bash
# Godot Editor 4.7 打开 project.godot，F5 运行
# Headless 编译检查
Godot.exe --headless --path kids-park --quit-after 60
# E2E 自动化测试（21 项断言全 [PASS]）
KIDS_PARK_E2E=1 Godot.exe --headless --path kids-park
# 打包 Android APK
Godot.exe --headless --path kids-park --export-debug "Android Debug"
```

- **桌面**：WASD 移动，Space 跳跃。
- **触屏**：左下虚拟摇杆移动，右侧大按钮（≥80px，3 岁孩子也能点）。
- 4 个 autoload 单例：`EventBus` / `GameState` / `DailyQuests` / `ParkGen` / `AudioBus`。

## 设计哲学（不可违反）
1. **无惩罚**：没有 Game Over / 生命值 / 时间惩罚 / 敌人攻击（迷你游戏的"超时"只是温柔提示，无扣分）。
2. **即时正反馈**：每次拾取都有彩纸 + Toast + 音效。
3. **零文字依赖**：大图标 emoji + 颜色区分，3 岁孩子也能理解。
4. **简单操作**：左摇杆移动 + 右侧大按钮，触屏按钮 ≥80px。

---

## 核心玩法循环
1. **探索** → 在 4 个彩色区域自由走动（草地 🌳 / 沙滩 🏖️ / 花园 🌸 / 冰雪 ❄️）。
2. **拾取** → 走过发光物品自动拾取（2m 磁吸，风暴天磁吸 +50%），每次彩纸 + Toast + 音效。
3. **每日任务** → 每天 3 个任务（收集指定物 / 累计拾取 / 社交互动），完成拿奖励，全做完 +3 金星 + 贴纸。
4. **帮 NPC** → 按 **E** 和小动物互动，帮它找 N 个东西 → 完成获贴纸 + 宠物伴灵；提升友谊解锁角色故事。
5. **解锁** → 收集总数到阈值（10/20/35）解锁新区域。

## 每日任务系统（📅）

每天自动生成 3 个任务，跨会话持久化，新一天自动刷新：
- **收集类**：收集 N 个指定物品（在已解锁区域随机选）。
- **探索类**：累计拾取任意物品 M 个。
- **社交类**：和小动物互动 / 送礼 K 次。
- 单个完成：奖励物品（目标量 ×2）。全部完成：额外 +3 🌟金星 + 📅贴纸。

HUD 左上实时显示进度（如 `📅 1/3 · 🍎 3/5 · 🎁 6/10 · 💬 1/3`），按 Tab 第 4 个标签页查看详情。

## 成长 & 个性化系统

- 🧙 **魔法书**（M）：5 种永久技能（加速/高跳/磁吸/光源/三段跳），按收集总数（15/30/50/75/100）解锁。
- ❤️ **友谊值 & NPC 故事**：4 位 NPC 各有名字/性格/4 段故事，友谊等级（0-5）提升时解锁故事节拍。好友(3)给珍珠，知心(5)给贴纸。
- 🎩 **换装衣柜**（H）：4 帽子 × 6 围巾 × 7 身体染色 × 4 眼镜，全部持久化，开局自动应用。
- 📸 **拍照**（P 拍 / V 相册）：每区 1 个打卡景点，拍照获贴纸。
- 🐾 **宠物伴灵**：NPC 任务完成后跟随你的彩色小动物。
- 🌸 **季节**：春夏秋冬循环（每 2 天），全局色调变化。

## 天气系统（新）

全局天气状态机每 45-90 秒切换：☀️晴天 / 🌧️雨天 / 🌨️雪天 / ⛈️风暴。
- **视觉**：环境光亮度/色调随天气变化（雨天变暗蓝、雪天变亮、风暴更暗）。
- **玩法影响**（设施交互）：
  - 🌧️雨天 / ⛈️风暴 → 弹跳蘑菇蹦更高（踩水花！）。
  - ⛈️风暴 → 收集物磁吸范围 +50%（风把东西吹近）。
  - 🌨️雪天 → 滑梯滑行加速（低摩擦）。
- 右上角 HUD 显示当前天气图标。

## 存档系统（v2）

`GameState` 持久化到 `user://kidspark_state.json`：
- **版本号**：`SAVE_VERSION=2`，旧档自动迁移（`_migrate()`）。
- **原子写入**：写临时文件 → 校验 → 滚动备份 `.bak` → 重命名，任何中断都不会损坏现有存档。
- **损坏恢复**：主存档损坏时自动回退 `.bak` 备份。
- **字段守卫**：加载时逐字段类型校验，脏数据不会崩溃。
- **移动端三重保护**：关闭/返回/暂停时立即保存。
- 每日任务单独存 `user://kidpark_quests.json`。
